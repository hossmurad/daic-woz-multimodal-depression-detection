# Dataset

## 1. Overview

DAIC-WOZ (Distress Analysis Interview Corpus - Wizard of Oz)

## 2. Access

Request access: https://dcapswoz.ict.usc.edu

## 3. Structure

Each participant directory contains:
- AUDIO.wav (audio recording)
- TRANSCRIPT.csv (transcript)
- CLNF_AUs.txt (Action Units)
- CLNF_gaze.txt (gaze features)
- CLNF_pose.txt (head pose)
- COVAREP.csv (audio features)

## 4. Labels

PHQ-8 >= 10 -> Depressed. PHQ-8 < 10 -> Non-depressed.

## 5. Known Issues

- Missing transcripts: 451, 458, 480
- Labeling errors: 320, 325, 335, 344, 352, 356, 380, 386, 409, 413, 418, 422, 433, 459

## 6. Citation

Gratch, J., et al. (2014). The Distress Analysis Interview Corpus. LREC.
